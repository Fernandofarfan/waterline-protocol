# Waterline Protocol 🌊
### Solución Logística Web3 | Oracle Cloud + Avalanche

Este proyecto utiliza la infraestructura de **Oracle (OCI)** para la gestión de datos masivos y la red de **Avalanche** para la tokenización de activos reales (RWA).

## 🚀 Objetivos de la Hackathon
* Implementar bases de datos autónomas de Oracle para trazabilidad.
* Integrar agentes de IA para optimización de rutas.
* Documentar la conexión con Avalanche Subnets.
